# Posey 图标

应用图标与 README 使用已确认的 Cinna 相机头像：奶白头发、浅蓝内层、蓝眼睛、画面左侧螺旋发髻与右侧云朵发夹。Posey 姿势库内的业务人物保持原样。

- `docs/brand/cinna-app-icon.png`：512 px 透明圆角展示图，README 使用约 128 px。
- `mobile/assets/brand/posey-icon-master.png`：1024 px 方形母版，沿用同一画面并补齐背景。
- `mobile/assets/brand/posey-icon.png`：应用标题栏头像。
- `mobile/ios/Runner/Assets.xcassets/AppIcon.appiconset/`：不预切圆角的 iOS 图标，由系统遮罩。
- `mobile/android/app/src/main/res/mipmap-*/`：普通、圆形和自适应图标。
- `mobile/android/app/src/main/res/drawable/ic_launcher_monochrome.xml`：主题单色图标，沿用 Posey 相机符号。

平台尺寸使用确定性缩放。既有几何符号和字标留作业务图形，不作为当前彩色应用图标。小尺寸、深浅背景和系统遮罩分别检查；图标不代表功能截图。
