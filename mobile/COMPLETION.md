# 手机端功能收口

本轮按现有 Flutter 产品补齐功能，统一验收后交付。已移除的网页端、姿势检测、语音和自动快门保持历史状态。

- [ ] 拍摄与导入自动留存作品，重开可查看；删除、批量管理、保存相册和分享。
- [ ] 照片旋转、镜像和裁剪；原图与编辑、AI 成片对比，重拍与重新选参考。
- [ ] 相机预览、网格和参考使用同一视口；参考拖动、缩放、复位，镜像贯穿生成。
- [ ] 手动倒计时、点按对焦、缩放、权限入口与中断恢复。
- [ ] AI 服务连接检查、明确重试确认、任务配置快照、成片保存与继续生成。
- [ ] Android 原生后台队列、通知、取消和恢复；iOS 保持同一任务协议。
- [ ] 姿势步骤、场景、道具、机位提示；排序、最近使用，首页与收藏独立筛选及复位。
- [ ] 导入自有参考，命名、编辑与删除，保留相关作品。
- [ ] 独立处理收藏、设置、作品和任务损坏；备份后恢复，避免自动覆盖。
- [ ] 本机备份导出与校验后导入、存储统计、任务和临时文件清理。
- [ ] 深浅主题、首次使用流程、自然文案、小屏与大字号渲染。
- [ ] 稳定的本地签名与升级说明、双语 README、研究结构校验与平台构建。
- [ ] 关键流程与失败边界测试、Android / iOS 编译、最终安装包与源码对应。

物理相机、系统授权、真实 AI 服务与真机后台行为按实际执行记录，不将替身测试或模拟器编译记作真机通过。
